Request - Response

sto e request i sto response
HTTP (HyperText Transfer Protocol)
drugi protokoli: FTP protocol File transfer protocol, 
osnoven protocol e HyperTextTransferProtocol

se pusta request od sto se sotoi

sostaven del od sekoj request:
HTTP methods - sekoj request si sodrzi TIP get,post, put,patch, delete.
Headers - doobrasjnuvanje na request plus Useragend,assetlagnuage kakov tip na jazik, authorization, content-type, text, json, Request Line, HTTP METHOD, URL, HTTPVERSION (GET /hello.htm HTTP/1.1)
Body (opconalno) za get ne ni treba deka vika samo DAJ MI
a za POST ni treba

First digit – Represents the status category.
Second and third digits – Represent the specific result.

2xx success
3xx redirection
4xx client error
5xx server error
